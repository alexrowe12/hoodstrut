# Roadmap

Hoodstrut is currently focused on reproducible local benchmarking of Claude Code
profiles. Near-term work is intentionally biased toward benchmark credibility
and a useful task corpus rather than additional interfaces.

## Before 1.0

- Expand the bundled corpus across languages, ecosystems, and maintenance task
  types while keeping verification deterministic.
- Exercise public benchmark suites with repeated trials and publish the raw
  artifacts behind any comparative claims.
- Stabilize profile and task schemas based on real external usage.
- Improve diagnostics for Docker, credentials, model access, and unsupported
  Claude Code settings.
- Document compatibility and migration policy for stored result formats.

## Later

- Additional coding agents beyond Claude Code.
- Shareable suite registries and richer result visualization.
- Distributed or hosted execution after the local trust model is mature.

The roadmap is directional, not a commitment to dates or specific releases.
